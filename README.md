# ❤️ Heart Disease Prediction Web App

An end-to-end Machine Learning project that predicts the likelihood of heart disease using patient health data. Built with Python, Scikit-learn, and Streamlit.

# 📌 Project Overview

This project demonstrates a complete machine learning workflow including:

* Data preprocessing
* Exploratory Data Analysis (EDA)
* Feature engineering
* Model training and evaluation
* Model deployment using Streamlit

The web application allows users to enter medical details and receive instant heart disease predictions.

# ▶️ Run Locally

Clone the repository:

```bash
git clone https://github.com/tarunibabu2006-tech/heart-disease-prediction
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
